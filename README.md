# TAG TPAC 2026 Meeting (and Breakout) planning

This repo is being used to plan TAG's attendance of TPAC meetings and breakouts.

The planning is done via issues created in a specific format to be used with [tpac-scheduling-helper](https://github.com/matatk/tpac-scheduling-helper).

* [TPAC overview and attendance planning page](https://w3ctag.github.io/tpac2026-meetings/planning.html) - allows you to semi-automatically file those issues, via a list of all currently-timetabled TPAC events (timetabling of breakouts comes after timetabling of group meetings).

* [Group scheduling page](https://w3ctag.github.io/tpac2026-meetings/schedule.html) - highlights meetings that have moved, planned attendances that clash, and provides group members with individual timetables.
